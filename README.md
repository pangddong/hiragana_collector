# Hangul Data Collector

한글 자음 손글씨 이미지 데이터 수집을 위해 제작된 프로그램입니다.

## 기능
- 500x400 크기의 캔버스에 글씨 작성후 저장 가능
- 이미지 저장 시 흑백 + 이미지 크기 500x400으로 변환되어 저장(기본값)
- 'START'와 'LOAD' 버튼으로 처음부터/원하는 지점부터 실행가능
- 한글 자음 글씨 상단에 표기
- 닉네임_hangul_data 폴더를 생성하여 하위 데이터 관리
- 로마자 형식의 한글 자음 폴더 생성(닉네임_글자_번호)
- 캔버스 실행취소

## 단축키
- Ctrl + Z: 실행취소(undo)
- Space, Enter: 다음으로(complete)
- ESC: 캔버스 초기화(clear)

## 참고 사항
- 히라가나 수집용 프로그램에서 간단하게 변환한 버전이기에 발견되지 않은 문제가 있을 수 있습니다.
- 디스플레이 배율 100% 이외에서 사용 시 저장이 제대로 되지 않습니다.
- 실사용 겸 학습용으로 제작되었기에 주석이 과하게 포함될 수 있습니다.
