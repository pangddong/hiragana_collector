# Hiragana Data Collector

히라가나 손글씨 이미지 데이터 수집을 위해 제작된 프로그램입니다.

## 기능
- 500x400 크기의 캔버스에 글씨 작성후 저장 가능
- 이미지 저장 시 흑백 + 이미지 크기 500x400으로 변환되어 저장(기본값)
- 'START'와 'LOAD' 버튼으로 처음부터/원하는 지점부터 실행가능
- 히라가나 글씨 상단에 표기
- 로마자 형식의 히라가나 폴더 생성

## 참고 사항
- 히라가나 수집을 위해 만들었지만 다른 드로잉 이미지 수집시에도 사용 가능하게 염두하여 제작되었습니다.
- 실사용 겸 학습용으로 제작되었기에 주석이 과하게 포함될 수 있습니다.
